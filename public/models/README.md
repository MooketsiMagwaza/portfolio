# Third-party model

`retro-tvs.glb` is an optimized derivative of **Retro TVs (3 Variations)
(2K)** by [Minh Nguyen](https://sketchfab.com/Minh_Nguyen_2004), sourced from
[Sketchfab](https://sketchfab.com/3d-models/retro-tvs-3-variations-2k-b608feee069e46d3a0dd2fe171f9f9ca)
and used under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).

The original 9.69 MB model was losslessly reorganized and its textures were
resized and converted to WebP for web delivery. The resulting model is about
427 KB. This asset is **not** covered by this repository's MIT License and must
not be used commercially without separate permission from its creator.
